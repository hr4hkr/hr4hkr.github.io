Understanding the target first

The notebook labels loan status 1 as a defaulter and 0 as a non-defaulter. In the supplied training table, the saved class summary is about 9.26% defaults and 90.74% non-defaults. I reviewed missing values, categorical fields, numeric distributions, and correlations before comparing models.

Modeling workflow

  1. Inspect the 35 columns and identify missing loan amount and term values.
  2. Explore category counts and numeric summaries, including the target imbalance.
  3. Encode categorical features and use SMOTE to create a more balanced modeling set.
  4. Compare a Random Forest classifier with a Decision Tree using classification reports and confusion matrices.

What the saved scores show

On the notebook’s balanced test split, the Random Forest reports 91.55% accuracy, 86.65% recall, and 91.12% F1 for the positive class. The Decision Tree reports 82.74% accuracy and 85.04% positive-class recall. These figures describe the saved run, but they are not a reliable estimate of performance on naturally imbalanced future applicants.

Validation caveat. SMOTE is applied to the full dataset before the train/test split. Synthetic examples can therefore influence both sides of the evaluation, and the test set is balanced unlike the original 9.26% default share. The notebook also applies the Loan Amount mode to the whole frame before attempting a Term fill. Both steps need correction before the scores can be used to compare real-world model performance.

Next iteration

Split the original data first with stratification, fit preprocessing and resampling on training data only, impute each feature separately, and evaluate on an untouched holdout at the natural class ratio. Report class-specific precision, recall, PR AUC, and a threshold selected for the business cost of missed defaults. The categorical plotting grid also needs room for all nine categories.
